# UPI Transactions Analysis Dashboard

### Interactive Financial Data Analysis using Microsoft Excel

## 📌 Project Overview

This project focuses on analysing UPI transaction data using Microsoft Excel to understand transaction patterns, payment behaviour and transaction performance.

An interactive dashboard was developed to visualise transaction trends, monitor successful and failed payments, and explore different transaction categories.

## 🎯 Project Objectives

- Analyse overall UPI transaction performance.
- Identify successful and failed transactions.
- Understand transaction patterns across different payment types.
- Analyse transaction trends over time.
- Explore transaction status and payment behaviour.
- Present financial data through an interactive dashboard.

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers and Timelines
- Data Cleaning
- Data Analysis
- Interactive Dashboard Design

## 📊 Dashboard Features

### Key Analysis Areas

- Total transaction analysis
- Successful vs. failed transactions
- Transaction type distribution
- Transaction status analysis
- Time-based transaction trends

### Interactive Features

- PivotTables for data summarisation
- Charts for visual analysis
- Slicers for interactive filtering
- Timeline for date-based analysis

- CSV Dataset – Source data used for analysis.
